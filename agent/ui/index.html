Allsafe Agent

Que veux-tu faire ?

Installation

Réparation

Réenregistre le service Windows et corrige le PATH système, sans toucher à l'enrôlement existant (le jeton n'est pas redemandé). À utiliser si le service ne démarre plus ou si allsafe-agent n'est plus reconnu en ligne de commande.

Mise à jour

Désinstallation

Arrête et désenregistre le service Windows, retire l'entrée PATH, supprime la configuration (%ProgramData%\allsafe-agent) et le dossier d'installation (Program Files\Allsafe Agent) — cette fenêtre se ferme automatiquement une fois lancé, le temps de libérer son propre fichier avant de le supprimer.
